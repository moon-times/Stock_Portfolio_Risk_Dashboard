사용자가 지목한 **티켓 하나**를 구현한다.

## 가장 중요한 규칙

**티켓에 없는 것은 만들지 않는다.**

"이것도 있으면 좋을 것 같아서" 추가하지 않는다. 로그인, 다크모드, 애니메이션, 설정 화면 — 티켓에 없으면 안 만든다.
꼭 필요하다고 판단되면 **만들지 말고 사용자에게 한 줄로 묻는다.**

## 절차

### 1. 티켓을 읽는다

`tickets.md` 에서 해당 티켓을 찾는다. `CLAUDE.md` 와 `specs/tech-stack.md` 도 읽는다 — **거기 적힌 기술 말고 다른 걸 쓰지 않는다.**

### 2. 확인 항목을 먼저 소리 내어 옮겨 적는다

구현을 시작하기 전에, 그 티켓의 Given / When / Then 을 **그대로 화면에 출력한다.**
이게 오늘 만들 것의 전부다. 여기 없는 건 안 만든다.

### 3. 만든다

가장 단순한 방법으로 만든다. 라이브러리를 새로 설치하지 않는다 — `specs/tech-stack.md` 에 있는 것만 쓴다.
파일을 여러 개로 쪼개지 않는다. 학생 프로젝트다.

### 4. 사람이 확인할 수 있게 넘긴다

**테스트 프레임워크를 설치하지 않는다.** 대신 다 만든 뒤 이렇게 출력한다.

```
## 확인해 주세요

1. <파일을 어떻게 여는지 — 예: index.html 을 브라우저로 연다>

그리고 아래를 하나씩 직접 해 보세요.

- [ ] Given … / When … / Then …
- [ ] Given … / When … / Then …
```

**"다 됐습니다" 라고만 말하고 끝내지 않는다.** 사람이 손가락으로 무엇을 눌러야 하는지 반드시 적는다.

### 5. 커밋한다

확인 목록을 출력한 뒤 커밋한다. 커밋 메시지는 티켓 제목을 그대로 쓴다.

### 6. 마지막 한 줄

**"검사원 서브에이전트로 이 티켓을 검사해줘 — 라고 치시면 제가 스스로 점검합니다."**
