# REQUIREMENTS — 포트폴리오 리스크 대시보드

| 항목 | 내용 |
|---|---|
| 문서 버전 | 2.0 (실제 API 스펙 반영) |
| 최종 수정 | 2026-08-26 |
| 선행 문서 | `docs/PRD.md`, `docs/TRD.md` |

---

## 0. 표기 규칙

| 접두어 | 의미 |
|---|---|
| `FR-` | 기능 요구사항 (Functional Requirement) |
| `NFR-` | 비기능 요구사항 (Non-Functional Requirement) |
| `CON-` | 제약사항 (Constraint) |

| 우선순위 | 의미 |
|---|---|
| **P0** | 없으면 데모 불가. 반드시 구현 |
| **P1** | 있으면 좋음. 시간 남으면 구현 |
| **P2** | v2 이후 |

용어: **MUST**(반드시), **SHOULD**(권장), **MUST NOT**(금지).
